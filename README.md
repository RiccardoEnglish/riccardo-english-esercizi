# Riccardo English · Esercizi

Piattaforma di esercizi di inglese (Path to Fluency).

- `site/index.html` è la versione pubblicata (un solo file).
- `src/` contiene il sorgente e i contenuti del livello A1 (`src/a1/data*.js`).
- `export/a1-contenuti.json` contiene guide e domande A1 in JSON, riusabili in altre piattaforme.
